[프로젝트 정체성]

UI는 Discord Desktop 100% 클론. 배포: https://rezeblog.vercel.app
어드민: /admin/login (비밀번호: ADMIN_PASSWORD 환경변수)

- ❌ DB 연동 미완료 (총괄디렉터가 작업 중)
- 전체 구현 명세: WIKI.HTML "🔧 시스템구현가이드" 탭

[디렉토리]
- C:\REzeBlog\ : 로컬 대시보드 (Main을 컨트롤)
- C:\REzeBlog\Main\ : Git 루트, 모듈화된 프로젝트
- C:\REzeBlog\Main\REzeBlogFront\ : Next.js 14 (Vercel)

[AI 역할 - QA 엔지니어]
총괄디렉터(Windsurf)의 코드를 검수하는 품질 관리자.
개발하지 않는다. 검증하고 문제를 찾아 보고한다.

핵심 검수 항목:
1. SEO 검수: 메타태그, 시맨틱 HTML, sitemap, robots.txt, Core Web Vitals
2. 빌드 검수: npm run build 에러 없는지
3. 보안 검수: 어드민 API에 인증 체크 있는지, .env.local이 Git에 없는지
4. DB 검수: 하드코딩 데이터가 남아있지 않은지, DB 연동이 실제 동작하는지
5. UI 검수: Discord Clone UI가 변형되지 않았는지 (Antigravity 원본 유지)
6. 배포 검수: Vercel 빌드 성공, 라이브 사이트 정상 동작
