# Next.js 14로 1인 개발 블로그 만들기

**1인 개발자를 위한 풀스택 실전 가이드**

## 왜 Next.js 14인가?

**Next.js 14**는 1인 개발자에게 최적화된 프레임워크입니다. **React Server Components**, **App Router**, **서버리스 배포**가 모두 통합되어 있어 빠르게 프로덕션 수준의 서비스를 출시할 수 있습니다.

### Next.js 14의 강점

| 기능 | 이점 | 1인 개발자에게 |
|------|------|---------------|
| **App Router** | 파일 기반 라우팅 | 별도 설정 없이 SEO 친화적 URL |
| **Server Components** | 서버 사이드 렌더링 | 빠른 초기 로딩 + 검색엔진 최적화 |
| **Edge Functions** | 전역 배포 | 무료 티어로 전 세계 CDN 활용 |
| **Image Optimization** | 자동 최적화 | 별도 설정 없이 WebP, 반응형 이미지 |

## Database 연동: PostgreSQL + Prisma

### 1. 스키마 정의

```prisma
// schema.prisma
model Post {
  id          String   @id @default(uuid())
  title       String
  slug        String   @unique
  excerpt     String
  content     String
  category    Category @relation(fields: [categoryId], references: [id])
  categoryId  String
  publishedAt DateTime @default(now())
  isPublished Boolean @default(false)
  seoMetadata SeoMetadata?
  
  @@index([slug])
  @@index([publishedAt])
}

model SeoMetadata {
  id          String   @id @default(uuid())
  post        Post     @relation(fields: [postId], references: [id])
  postId      String   @unique
  metaTitle   String?
  metaDescription String?
  keywords    String[]
  ogImage     String?
}
```

### 2. Server Actions

```typescript
// app/blog/actions.ts
'use server'

import { revalidatePath } from 'next/cache';
import { prisma } from '@/lib/prisma';

export async function createPost(data: CreatePostInput) {
  const post = await prisma.post.create({
    data: {
      ...data,
      seoMetadata: {
        create: data.seoMetadata
      }
    },
    include: {
      seoMetadata: true
    }
  });
  
  revalidatePath('/blog');
  revalidatePath(`/blog/${post.slug}`);
  
  return post;
}

export async function getPostBySlug(slug: string) {
  return prisma.post.findUnique({
    where: { slug },
    include: { 
      seoMetadata: true,
      category: true 
    }
  });
}
```

## SEO 최적화 전략

### 1. 메타데이터 자동 생성

```typescript
// lib/seo.ts
export function generateSeoMetadata(post: Post): Metadata {
  const title = post.seoMetadata?.metaTitle || post.title;
  const description = post.seoMetadata?.metaDescription || post.excerpt;
  const keywords = post.seoMetadata?.keywords || extractKeywords(post.content);
  
  return {
    title: `${title} | REzeBlog`,
    description,
    keywords,
    authors: [{ name: post.author }],
    openGraph: {
      title,
      description,
      type: 'article',
      publishedTime: post.publishedAt.toISOString(),
      authors: [post.author],
      images: [post.seoMetadata?.ogImage],
    },
    twitter: {
      card: 'summary_large_image',
      title,
      description,
    },
    alternates: {
      canonical: `/blog/${post.slug}`,
    },
    robots: {
      index: post.isPublished,
      follow: post.isPublished,
    }
  };
}
```

### 2. 구조화 데이터 (JSON-LD)

```typescript
// components/structured-data.tsx
export function BlogPostStructuredData({ post }: { post: Post }) {
  const jsonLd = {
    '@context': 'https://schema.org',
    '@type': 'BlogPosting',
    headline: post.title,
    description: post.excerpt,
    image: post.seoMetadata?.ogImage,
    datePublished: post.publishedAt.toISOString(),
    dateModified: post.updatedAt?.toISOString() || post.publishedAt.toISOString(),
    author: {
      '@type': 'Person',
      name: post.author,
    },
    publisher: {
      '@type': 'Organization',
      name: 'REzeBlog',
      logo: {
        '@type': 'ImageObject',
        url: 'https://rezeblog.vercel.app/logo.png'
      }
    },
    mainEntityOfPage: {
      '@type': 'WebPage',
      '@id': `https://rezeblog.vercel.app/blog/${post.slug}`
    }
  };

  return (
    <script
      type="application/ld+json"
      dangerouslySetInnerHTML={{ __html: JSON.stringify(jsonLd) }}
    />
  );
}
```

```typescript
// lib/db.ts
import { cache } from 'react';

export const getPostBySlug = cache(async (slug: string) => {
  return prisma.post.findUnique({
    where: { slug },
    include: { seoMetadata: true }
  });
});

export const getAllPosts = cache(async () => {
  return prisma.post.findMany({
    where: { isPublished: true },
    orderBy: { publishedAt: 'desc' }
  });
});
```
