# 텍스트 게임 개발 입문

**코드 없이 시작해서 Next.js로 진화하는 단계별 가이드**

## 텍스트 게임이란?

**텍스트 게임(Text-Based Game)** 또는 **인터랙티브 픽션(Interactive Fiction)**은 이미지와 영상 대신 **글로 이루어진 게임**입니다. Zork, Choice of Games, 80 Days 같은 명작들이 이 장르를 대표합니다.

### 왜 텍스트 게임인가?

| 장점 | 설명 | 1인 개발자에게 |
|------|------|---------------|
| **낮은 진입장벽** | 그래픽 없이 시작 가능 | 혼자서 완성 가능 |
| **무한한 스토리** | 상상력이 그래픽을 대체 | 제작 비용 최소화 |
| **높은 몰입도** | 독자가 상상하며 참여 | 평균 체류 시간 증가 |
| **SEO 친화적** | 텍스트 기반 콘텐츠 | 검색엔진 인덱싱 용이 |

## 단계 1: 코드 없이 시작 (Twine)

### Twine이란?

**[Twine](https://twinery.org/)**은 코드를 몰라도 텍스트 게임을 만들 수 있는 무료 도구입니다. 비주얼 노드 에디터로 스토리 구조를 설계합니다.

### Twine 기본 사용법

```
[시작]
  │
  ├─→ [선택지 A: 문을 연다]
  │     └─→ [결과 A-1: 복도 발견]
  │
  ├─→ [선택지 B: 창문을 본다]
  │     └─→ [결과 B-1: 야경 발견]
  │
  └─→ [선택지 C: 가방을 확인한다]
        └─→ [결과 C-1: 열쇠 발견]
```

### Twine 스크립트 예시

```twine
:: 시작
당신은 어둠 속에서 눈을 뜹니다. 주변은 침묵에 싸여 있습니다.

[[불을 켠다->불 켜짐]]
[[어둠 속을 탐험한다->어둠 탐험]]
[[소리를 지른다->소리 지름]]

:: 불 켜짐
라이터를 찾아 불을 켭니다. 이곳은 버려진 지하실입니다.

[[노트북을 확인한다->노트북 발견]]
[[출구를 찾는다->출구 탐색]]

:: 어둠 탐험
조심스럽게 손을 뻗습니다. 차가운 벽이 닿습니다.

[[벽을 따라간다->벽 따라가기]]
[[제자리에 남는다->제자리]]
```

### Twine 장단점

| 장점 | 단점 |
|------|------|
| ✅ 시각적 스토리 설계 | ❌ 복잡한 로직 제한적 |
| ✅ HTML5 자동보내기 | ❌ 멀티플레이어 불가 |
| ✅ JavaScript 확장 가능 | ❌ DB 연동 어려움 |

## 단계 2: 고급 스크립팅 (Ink)

### Ink 언어란?

**[Ink](https://www.inklestudios.com/ink/)**은 80 Days, Sorcery! 시리즈로 유명한 Inkle Studios가 개발한 스크립트 언어입니다. Twine보다 **강력한 로직**을 제공합니다.

### Ink 기본 문법

```ink
// 변수 선언
VAR health = 100
VAR has_key = false
VAR turn = 1

// 메인 스토리
-> start

=== start ===
턴 {turn}: 어둠 속에서 눈을 뜹니다.

+ [불을 켠다] -> light_fire
+ [어둠 속을 탐험한다] -> explore_dark
+ [소리를 지른다] -> call_help

=== light_fire ===
~ turn += 1
라이터를 켭니다. 체력: {health}%

{turn > 5:
    → 시간이 부족합니다! -> bad_ending
- else:
    + [책상을 본다] -> check_desk
    + [출구를 찾는다] -> find_exit
}

=== check_desk ===
~ has_key = true
노트북 위에서 열쇠를 발견했습니다!

+ [출구로 간다] -> find_exit

=== find_exit ===
{has_key:
    열쇠로 문을 열고 탈출합니다! -> good_ending
- else:
    문이 잠겨 있습니다. → explore_dark
}

=== good_ending ===
축하합니다! 생존했습니다.
-> END

=== bad_ending ===
시간이 다 되었습니다...
-> END
```

### Ink 장점

1. **변수 시스템**: 체력, 인벤토리 등 상태 관리
2. **조건문**: 복잡한 분기 로직
3. **함수**: 재사용 가능한 스토리 블록
4. **Unity/C# 통합**: 고급 게임 엔진 연동

## 단계 3: 웹 기반 게임 (Next.js)

### 왜 Next.js인가?

Twine/Ink로 프로토타입을 만들고, **Next.js로 웹 서비스화**하는 것이 최종 목표입니다:

| 기능 | Twine/Ink | Next.js |
|------|-----------|---------|
| SEO | ❌ 제한적 | ✅ 완벽한 SSR |
| 분석 | ❌ 기본 | ✅ GA4, Mixpanel |
| 저장 | ❌ 로컬 | ✅ DB 연동 |
| 멀티 | ❌ 불가 | ✅ 실시간 가능 |
| 수익 | ❌ 어려움 | ✅ 광고/구독 |

### Next.js 텍스트 게임 구조

```typescript
// types/game.ts
interface GameState {
  currentBranch: string;
  turn: number;
  inventory: string[];
  flags: Record<string, boolean>;
  stats: {
    health: number;
    sanity: number;
    score: number;
  };
}

interface Branch {
  id: string;
  title: string;
  content: string;
  choices: Choice[];
  effects?: GameEffect[];
}

interface Choice {
  id: string;
  text: string;
  nextBranchId: string;
  condition?: (state: GameState) => boolean;
  effects?: GameEffect[];
}

type GameEffect = 
  | { type: 'ADD_ITEM'; item: string }
  | { type: 'REMOVE_ITEM'; item: string }
  | { type: 'SET_FLAG'; key: string; value: boolean }
  | { type: 'MODIFY_STAT'; stat: keyof GameState['stats']; delta: number };
```

### 게임 엔진 구현

```typescript
// lib/game-engine.ts
export class GameEngine {
  private state: GameState;
  private branches: Map<string, Branch>;

  constructor(initialState: GameState, branches: Branch[]) {
    this.state = initialState;
    this.branches = new Map(branches.map(b => [b.id, b]));
  }

  getCurrentBranch(): Branch {
    return this.branches.get(this.state.currentBranch)!;
  }

  getAvailableChoices(): Choice[] {
    const branch = this.getCurrentBranch();
    return branch.choices.filter(choice => 
      !choice.condition || choice.condition(this.state)
    );
  }

  makeChoice(choiceId: string): GameState {
    const branch = this.getCurrentBranch();
    const choice = branch.choices.find(c => c.id === choiceId);
    
    if (!choice) throw new Error('Invalid choice');
    
    // Apply effects
    const effects = [...(branch.effects || []), ...(choice.effects || [])];
    this.applyEffects(effects);
    
    // Move to next branch
    this.state.currentBranch = choice.nextBranchId;
    this.state.turn += 1;
    
    return { ...this.state };
  }

  private applyEffects(effects: GameEffect[]) {
    effects.forEach(effect => {
      switch (effect.type) {
        case 'ADD_ITEM':
          this.state.inventory.push(effect.item);
          break;
        case 'SET_FLAG':
          this.state.flags[effect.key] = effect.value;
          break;
        case 'MODIFY_STAT':
          this.state.stats[effect.stat] += effect.delta;
          break;
      }
    });
  }

  saveToDatabase(userId: string) {
    return saveGameState(userId, this.state);
  }
}
```

### React 컴포넌트

```typescript
// components/game-screen.tsx
'use client';

import { useState, useCallback } from 'react';
import { GameEngine } from '@/lib/game-engine';

export function GameScreen({ initialState, branches }: GameScreenProps) {
  const [engine] = useState(() => new GameEngine(initialState, branches));
  const [state, setState] = useState(initialState);
  const [isLoading, setIsLoading] = useState(false);

  const currentBranch = engine.getCurrentBranch();
  const availableChoices = engine.getAvailableChoices();

  const handleChoice = useCallback(async (choiceId: string) => {
    setIsLoading(true);
    
    const newState = engine.makeChoice(choiceId);
    setState(newState);
    
    // Auto-save
    await engine.saveToDatabase('user-id');
    
    setIsLoading(false);
  }, [engine]);

  return (
    <div className="game-screen">
      <GameStats stats={state.stats} />
      
      <StoryText content={currentBranch.content} />
      
      <ChoiceList 
        choices={availableChoices}
        onChoice={handleChoice}
        disabled={isLoading}
      />
      
      <Inventory items={state.inventory} />
    </div>
  );
}
```

## 스토리 설계 원칙

### 1. 3막 구조

```
[1막: 설정]
- 캐릭터 소개
- 세계관 설명
- 첫 번째 분기 (3개 선택지)

[2막: 전개]
- 갈등 심화
- 하위 목표 설정
- 복수 분기 (총 9개 경로)

[3막: 결말]
- 최종 선택
- 엔딩 분기 (3-5개)
- 후일담 (optional)
```

### 2. 선택지 설계

**좋은 선택지:**
- ✅ 각각 다른 결과로 이어짐
- ✅ 캐릭터 성격 드러냄
- ✅ 도덕적 딜레마 포함

**피해야 할 선택지:**
- ❌ "예/아니오"만 있는 단순 선택
- ❌ 결과가 똑같은 가짜 선택
- ❌ 이전 선택과 무관한 갑작스러운 전개

### 3. 진행도 시스템

```typescript
// 플레이어에게 진행 상황 표시
function ProgressBar({ state }: { state: GameState }) {
  const totalBranches = 15; // 총 분기 수
  const visitedBranches = new Set(state.visitedBranches).size;
  const progress = (visitedBranches / totalBranches) * 100;
  
  return (
    <div className="progress-bar">
      <div 
        className="progress-fill" 
        style={{ width: `${progress}%` }}
      />
      <span>{Math.round(progress)}% 완료</span>
    </div>
  );
}
```
