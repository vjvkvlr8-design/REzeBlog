# 하데스 (Hades) 시스템

하데스 시스템은 프로젝트의 품질과 일관성을 강제하는 범용 모듈 시스템입니다.

## 개요

하데스 시스템은 다음과 같은 구성 요소로 이루어져 있습니다:

- **정체성.txt**: 프로젝트의 정체성과 규칙을 정의하는 핵심 문서
- **게이트/**: CLI와 pre-commit 게이트 스크립트
- **설정/**: pre-commit 설정 파일
- **훅스/**: Git 훅 파일
- **지침/**: Copilot 지침 파일

## 설치

새로운 프로젝트에 하데스 시스템을 적용하려면:

1. 하데스 폴더를 프로젝트 루트에 복사하거나,
2. `install_하데스.py` 스크립트를 실행하세요:

```bash
python install_하데스.py
```

## 사용법

### 1. 정체성 정의
프로젝트의 `정체성.txt` 파일을 편집하여 프로젝트의 정체성과 규칙을 정의하세요.

### 2. 게이트 실행
새로운 작업을 시작하기 전에 게이트를 실행하세요:

```bash
python 하데스/게이트/cli_gate.py
```

### 3. Git 커밋
pre-commit 훅이 자동으로 품질 검사를 수행합니다.

## 특징

- **범용성**: 어떤 프로젝트에도 적용 가능
- **강제성**: 정체성.txt의 규칙을 자동으로 적용
- **자동화**: Git 훅과 pre-commit으로 자동 품질 관리
- **확장성**: 새로운 게이트와 규칙을 쉽게 추가 가능

## 요구사항

- Python 3.8+
- Git
- pre-commit (선택사항, 자동 설치 권장)

## 라이선스

이 시스템은 공개 도메인입니다. 자유롭게 사용하고 수정하세요.
